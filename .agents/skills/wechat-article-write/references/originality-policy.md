# 原创度政策

平台推荐标准青睐提供信息增量或情绪价值的内容；低创作度内容（同质化、搬运洗稿、低信息量、低价值 AIGC）不适合推荐。本文件是原创度契约的单一事实源；SKILL.md 与各策略文件只指向它，不复述。

## Primary Source Uniqueness

同一个 primary source 不应产生第二篇新的博客文章。Step 1.5 只对 `materials.md` 的
`## 原始来源` 中 `- url:` 项与已发布文章的 `primarySourceUrls`（旧文章则使用
`legacy-first-reference` compatibility fallback）做 normalized source identity exact match；
不做语义相似度判断，也不把 `## 背景调研` 或 `## 参考资料` 的 supporting references 纳入比较。

发现重复后必须停止创建新文章：已有文章仍有效则不再写；有重要新信息则更新已有文章；多来源任务
则删除已覆盖 source 后重跑 Step 1 / 1.5；全部核心来源都已覆盖则停止。不同 source 即使主题相近，
仍按本文件后续的增量契约判断；同一 source 即使有三条原创增量，也不能建立第二个 URL。没有普通
override/escape hatch。

## 增量契约

`understanding-brief.md` 的 `## 写作契约` 必须列出 ≥3 条增量承诺，从以下四类选取：

| 增量类型 | 写什么 |
|---|---|
| 第一人称经验/实践 | 作者自己做过的仓库、实测、踩坑、运营经验与本文主题的交接 |
| 独立判断 | 对材料结论的赞成/反驳/补充，带自己的立场与边界 |
| 跨来源连接 | 把材料与别的来源、站内旧文或其他领域事件连接，产出材料没有的新意义 |
| 预测或行动建议 | 给读者的可验证预测，或带具体场景的行动建议 |

draft 必须逐条落地增量承诺；Step 2 过程说明必须交增量自查（每条承诺落在正文哪一段）。写不出 3 条增量说明材料本身缺乏增量，先向用户说明理由再决定写法，不得直接写成纯搬运。

`tutorial` 策略的增量就是作者的实操经验本身：正文把第一人称经验与踩坑写明即可，不要求单独列承诺清单。

## 形式变体契约

写作前读取最近 5 篇已发布文章（`src/content/docs/articles/`，按 frontmatter `date` 排序）的标题、首段与
正文 H2 数量，登记：

- 标题模式：冒号二段式 / 疑问式 / 断言式 / 平铺式
- 标题修辞骨架：标题怎样组织读者注意力与中心判断，例如疑问引导、场景/人物切入、数据冲击、来源事件切入、
  直接结论、对比/冲突、反常识转折、“真正本质”揭示、过程变化、具体动作/结果、条件判断。此处不是固定枚举，
  应按实际标题概括。
- 开头模式：来源概述式 / 场景式 / 问题式 / 结论先行式 / 数据先行式
- 章节数：正文 H2 数量

本篇的四项组合（标题模式、标题修辞骨架、开头模式、正文 H2 数量）不得与最近 2 篇中任何一篇完全相同，
Step 2 过程说明必须交代差异。白名单内轮换；不为变体而变体，脱离品牌调性。

标题修辞骨架是编辑判断，不是关键词规则。不使用关键词黑名单：严禁把“真正”“首先”“最先”“分水岭”或
“不是……而是……”做成禁用词，也不引入 embedding、相似度模型、标题注册表或 regex blocker。

在正式冻结标题前，Main 至少考虑 3 个不同修辞骨架的候选，只保留最终标题，不把候选写入
artifact、receipt 或返回 Main 的长列表。优先级始终是语义准确、读者价值，再是修辞多样性；不能为了差异牺牲
信息量、清晰度或与正文 thesis 的一致性。

本篇标题默认不得与最近 3 篇重复同一主要修辞骨架。这是 `soft editorial default`，不是 deterministic hard
block；若内容确实最适合相同结构，Main 应确认这是内容驱动而不是语言惯性即可继续，不必向用户长篇解释。
如果最近 5 篇中已有至少 2 篇使用“真正 / 首先 / 最先 / 分水岭 / 不是 A 而是 B”这类“揭示真实本质”式 framing，
当前文章应主动尝试其它表达结构，优先从具体场景、动作、冲突、数据、直接问题、事件结果、人物/组织行为或条件判断切入。

因此，Step 2 形式自查登记四项：标题 broad mode、标题 rhetorical skeleton、opening mode、H2 structure；
上述提醒都是软规则，不阻断内容驱动的高质量标题。

## 节奏软感知

Step 0 统计近 7 天篇数与分类分布，向用户一句话报告。近 7 天 ≥7 篇或同一分类连排 ≥3 篇时，提出间隔调整或换体裁建议（插入 tutorial / 实践笔记 / 观点文）。只建议不阻断；节奏决定权在用户。
